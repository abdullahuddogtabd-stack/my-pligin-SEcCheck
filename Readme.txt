## যেগুলো এখন পরিবর্তন না করাই ভালো

এই internal names শুধু branding-এর জন্য পরিবর্তন করবেন না:

```text
ubd-security-auditor
UBD_Security_Auditor
UBD_SA_VERSION
UBD_SA_FILE
UBD_SA_DIR
UBD_SA_URL
ubd_sa_
ubd-security-auditor.php
```

এগুলোর মধ্যে রয়েছে:

* PHP class name
* WordPress option names
* nonce/action names
* menu slug
* CSS handle
* text domain
* internal constants
* plugin folder এবং main file

এগুলো পরিবর্তন করলে সমস্যা হতে পারে:

* পুরোনো report খুঁজে না পাওয়া
* duplicate plugin হিসেবে দেখা
* old plugin update না হওয়া
* Tools page broken হওয়া
* form submission কাজ না করা
* uninstall process incorrect হওয়া

শুধু client-facing নাম পরিবর্তন করতে হলে `ShieldScan` এবং lowercase `shieldscan` filename prefix পরিবর্তন করাই যথেষ্ট।

## Full rebrand করতে চাইলে

সম্পূর্ণ internal rebrand করতে হলে একসঙ্গে সব জায়গায় পরিবর্তন করতে হবে:

```text
Folder:
ubd-security-auditor
→ secureguard

Main file:
ubd-security-auditor.php
→ secureguard.php

Class:
UBD_Security_Auditor
→ SecureGuard

Prefix:
ubd_sa_
→ secureguard_

Text domain:
ubd-security-auditor
→ secureguard

Page slug:
ubd-security-auditor
→ secureguard
```

কিন্তু এতে WordPress পুরোনো plugin এবং নতুন plugin-কে আলাদা plugin মনে করতে পারে। তাই existing client website update করার ক্ষেত্রে internal names অপরিবর্তিত রেখে শুধু visible branding পরিবর্তন করাই নিরাপদ।
